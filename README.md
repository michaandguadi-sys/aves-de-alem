# Aves de Alem

Bird ID app for Misiones, Argentina. Open it on your phone and add it to the home screen:
https://michaandguadi-sys.github.io/aves-de-alem/

- **Sound ID:** BirdNET V2.4 running on the device (works offline after a one-time ~64 MB download)
- **Photo ID:** Claude vision with your own Anthropic API key
- **Explore:** iNaturalist records within 40 km, species expected this week, all 11,004 living bird species worldwide (search any name, browse order → family → species), a 55-species Misiones field guide
- **Species pages:** photos, recordings, taxonomy, IUCN and national status, body mass, diet and foraging (EltonTraits), seasonality near you, distribution map, commonly confused species, Wikipedia sections, optional AI ornithologist notes
- **Journal & game:** counts, notes, photos, XP, levels, badges, weekly challenges, backup/restore
